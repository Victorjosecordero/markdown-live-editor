# Markdown Live Editor

Editor Markdown en vivo creado con HTML, CSS y JavaScript, sin dependencias de ejecución.

## Funciones

- Vista previa en tiempo real
- Barra de formato y atajos de teclado
- Exportación a Markdown y HTML autocontenido
- Copia del HTML generado
- Autoguardado en el navegador
- Diseño responsive y accesible

## Uso local

Abre `index.html` directamente o sirve la carpeta con cualquier servidor estático.

## Atajos

- `Ctrl/Cmd + B`: negrita
- `Ctrl/Cmd + I`: cursiva
- `Ctrl/Cmd + S`: exportar Markdown
- `Ctrl/Cmd + Shift + S`: exportar HTML
